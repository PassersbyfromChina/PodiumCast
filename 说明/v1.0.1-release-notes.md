**PodiumCast** — 多平台摄像头投屏与拍摄控制套件。一个摄像头，两个预览，可选两个存储。

> **本项目由 AI 编写 (AI-generated project)。**

本次为 **Bug 修复版**：上一版在真机上暴露了若干布局与控制问题，这一版逐条修掉，并补上了镜像与更简化的拍摄规格选择。

## 这一版修了什么

### 1. 控件条在非 16:9 屏幕上溢出、按钮被裁掉（安卓与 Windows 都受影响）

根因是**黑边方向的判断写反了**：比例计算把「画面比屏幕宽」判成了左右黑边，实际是上下黑边。于是每一档非 16:9 的屏幕都选了错误的一边，控件被放进**没有空余空间**的方向，只能从预览里挖地方；接着控件条又用固定网格 + `overflow: hidden`，放不下的按钮被直接裁掉。

- 现在黑边方向由一个**纯几何函数** `barAxis()` 决定，并有方向断言覆盖。
- 控件条改为**可换行的 flex 布局**，不再裁切任何东西。
- 黑边太窄放不下一行按键时，**改为悬浮控件**，而不是硬从预览里挖空间。
- 键盘密度分「标准 / 紧凑 / 极简」三档，由黑边实际像素决定（`planLayout()`）。
- 新增 **`npm run diagnose:layout`**：在 780×360（手机横屏）、640×360、1024×600、1280×720、1267×684、1920×1080 六档尺寸下启动真实窗口量几何。上一版在这六档里有三档溢出，现在 **12/12 通过**——包括大屏端。

### 2. 闲置时仍显示红色的 00:00 录制角标

`[hidden]` 属性被组件的 `display: inline-flex` 覆盖，隐藏不生效。已加全局 `[hidden] { display: none !important }`。

### 3. 退出应用或切换窗口后预览消失

- **大屏端**：之前只在合成层里保留一帧，窗口尺寸变化或从后台返回时画布会被清空。现在把最新一帧留在离屏画布上，尺寸变化、回到前台时重绘，画面不会掉。
- **拍摄端**：Android 切后台会挂起 WebView，回到前台时视频轨可能已经脱钩。现在回到前台会重新挂载仍在工作的视频轨；轨道真的结束了才重新打开摄像头。

### 4. Windows 把 Cast 与 Stage 认成同一个应用

两个应用由同一份源码构建，`package.json` 的 `name` 相同，而 Electron **用这个名字同时决定 userData 目录和单实例锁**。结果第二个启动的应用发现锁已被占用，就把参数转交给第一个然后自己退出——两个应用根本无法同时运行，还共用同一份设置与设备 ID。

现在每个角色有各自的 `app.setName()` 与 `app.setPath('userData')`，新增 **`npm run verify:roles`** 五项断言守护：两个角色可同时运行、userData 不同、重复启动同一角色会被锁挡住。

### 5. 拍摄规格选择过于复杂

上一版把硬件上报的组合摊成一张二三十行的表，还出现了 `32:27`、`8:3` 这种传感器根本不存在的比例——那是把 `width × height` 两个独立范围相乘算出来的。

现在改成**手机相机的三段式**：比例 / 清晰度 / 帧率，且**后两行只列出当前比例真实存在的档位**；下面一句完整说明当前组合，不可用的组合置灰。规格来自一份标准机型档位表，设备能力只用于*过滤*。完整硬件列表折叠在「高级」里。

### 6. 图标不统一、而且 Windows 图标看起来没对齐

- 实测发现旧图标在每一个尺寸上**圆心与圆环的偏差都是 0.00px**——几何没问题，问题在**笔画太细**：圆环只有 `0.055 × 尺寸 ≈ 1.8px`（32px 时），抗锯齿后一侧偏亮，看上去就像没对齐。
- 新标把圆环加粗到 `≥2px / 0.085 × 尺寸`，并在每个尺寸**单独渲染**而不是从小图缩放。
- **Android 的启动图标之前一直是 Capacitor 默认图标**——这一版才真正统一：桌面端 `.ico/.icns/.png`、Android 自适应图标（背景/前景/圆形/各密度）、网页 favicon 全部由 `scripts/make-icons.py` 一处生成。
- 该脚本会**逐像素校验**：圆心与圆环同心度、圆点是否为正圆、圆环四象限半径是否对称，偏差超过 0.35px 直接失败。

### 7. 其它

- 拍摄端横屏锁定（`sensorLandscape`），大屏端保持自由（`sensorFree`），适配竖装面板。
- 刘海/圆角安全区：预览与控制条都加了 `env(safe-area-inset-*)` 内边距，横屏时不遮挡读数与按钮。
- 测试画面不再渲染 4K 画布（手机上白白耗电），按所选比例压到 1080p 以内。

## 新增：镜像

拍摄端与大屏端各有**互相独立**的镜像开关：

| 位置 | 开关 | 影响 |
| --- | --- | --- |
| Cast | 镜像预览（工具栏按钮 / `M` 键 / 设置） | 本机预览 **和** 推送给大屏的画面 |
| Cast | 镜像录制（设置） | 录下的照片与视频**文件本身**；默认关闭 |
| Stage | 显示镜像（左下角抽屉 / `M` 键 / 设置） | 只翻这块大屏，不影响拍摄端 |

翻转在编码前的 canvas 上完成，录制则接一条 canvas 管线——**看到的、传出去的、录下来的三者一致**，不会出现「屏幕上镜像了、文件里是反的」。
