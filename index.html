PodiumCast

一个摄像头，两个预览，可选两个存储 —— 拍摄端与放大屏端分体协作。

下载发布页 · 源代码

这是什么

PodiumCast 把「拍」和「看」拆成两个独立应用，中间只走一条连接。

  • 一个摄像头：摄像头只接在 PodiumCast-Cast 这一侧（手机或带摄像头的电脑），拍摄、录制、回放都在这里发生。
  • 两个预览：Cast 上有一个实时预览；PodiumCast-Stage 在大屏上同时显示同一路画面，画面是实时同步的，不是拷过去的文件。
  • 可选远程操控：Stage 可以只是一个「显示器」，也可以打开控制面板，远程驱动 Cast 拍照、开始/停止录制、变焦与回放。
  • 可选两个存储：录制文件默认存在 Cast；也可以改成存在 Stage，或者两边各存一份，任意一侧都能向另一侧拉取文件。
  • 首次连接自动配规格：第一次连上大屏时，Cast 会读取大屏的分辨率、比例、帧率与色域，挑选相同或最接近的拍摄比例，避免放大屏后出现黑边或裁切。

两个应用

两端都需要安装：拍摄端跑在摄像头上，大屏端跑在要显示的机器上。可以装在同一台设备，也可以分装两台。

PodiumCast-Cast

拍摄端 / 摄像头侧

负责打开摄像头并维持实时预览，完成拍照、录像与回放，同时把画面推送给 Stage。录制规格（比例、分辨率、帧率、色域）在这里协商与切换；文件默认落盘在本机，也可以改存到 Stage 或两边同时保存。界面按横屏设计：当录制比例和屏幕比例不一致时，按键会自动排到预览外的黑边上，并允许你决定预览与按键的左右或上下关系。

连接方式

四种连接方式任选其一，功能完全一致；哪一端做 Cast、哪一端做 Stage 由你决定。

连接方式 什么时候用
本机（同一台设备） Cast 和 Stage 装在同一台电脑上，一个大屏预览、一个监看窗口，延迟最低，不需要任何网络。
局域网 手机或另一台电脑做 Cast、大屏电脑做 Stage，两端连同一个路由器或热点，自动发现后一键连接。
USB 数据线 现场没有可用 Wi-Fi、或局域网不稳定时；用数据线连接两台设备并开启 USB 调试，走线缆比无线更稳。
手动输入地址 自动发现被防火墙、访客网络或网段隔离挡住时；在 Stage 上直接填 Cast 显示的地址与端口（默认 8765）。

常见问题

下面几条是被问得最多的，答案尽量说实话。

需要联网吗？

不需要。PodiumCast 只在你的本机、局域网或 USB 线缆之间通信：同一台设备走回环地址，两台设备走路由器的内网，USB 走 adb reverse 把端口映射到本机回环。

整个过程不连接任何服务器，也没有账号、登录或云端中转。公网断开时照常工作；只有「下载安装包」和「检查更新」这两件事需要访问 GitHub。

为什么 Windows 安装包会提示「未知发布者」？

因为安装包没有做代码签名（EV 代码签名证书需要按年付费）。Windows SmartScreen 对没有签名的程序一律给出这个提示，它说明的是「没有签名」，不是「检测到病毒」。

继续安装的办法：在提示窗口点「更多信息」，再点「仍要运行」；如果已经被 SmartScreen 拦下，可以在文件上右键 → 属性 → 勾选「解除锁定」后重试。介意风险的话，可以先用 GitHub 上的源码自行构建。

macOS 首次打开提示「无法验证开发者」怎么办？

同样是签名与公证的问题：应用没有经过 Apple 公证，Gatekeeper 默认不放行。两种处理方式任选：

  • 在「访达」里按住 Control 点击（或右键）应用图标 → 选「打开」→ 在弹窗里再点一次「打开」。之后就可以正常双击启动。
  • 或者在终端里执行 xattr -d com.apple.quarantine /Applications/PodiumCast-Stage.app，把隔离标记去掉（路径按实际安装位置改）。

如果系统提示「已损坏」，基本都是隔离标记导致的，上面第二条命令即可解决。

录制文件存在哪里？

默认存在 PodiumCast-Cast 这一端，也就是接摄像头的设备上：Windows 与 macOS 版存在应用的媒体库里（可在应用内直接打开所在文件夹），Android 版存在应用私有目录，不写系统相册。

也可以把存储目标改成 PodiumCast-Stage，或者两边各存一份，在 Cast 或 Stage 的设置里切换即可。文件名按「类型 + 时间戳」生成，不会互相覆盖。

手机与电脑之间能互传文件吗？

可以。连接建立后，任意一端都能向另一端拉取文件：在 Stage 上可以查看 Cast 的媒体库并把照片、视频拉到大屏这台机器；反过来 Cast 也能从 Stage 拉回文件。

传输和实时预览共用同一条连接，走的还是本机 / 局域网 / USB 通道，不经过云端。传大文件时建议用 USB 数据线或 5 GHz 局域网。

支持哪些平台和录制规格？

平台：Windows x64、Windows x86（32 位）、Windows on ARM、macOS（Intel 与 Apple 芯片通用）、Android。

录制规格取决于设备摄像头实际支持的组合，比例、分辨率、帧率与色域都是协商出来的：Cast 打开时枚举可用组合，Stage 打开时上报大屏规格，第一次连接会挑相同或最接近的比例。之后你可以手动改，手动选择会一直生效。
