一个摄像头，两个预览。

PodiumCast-Cast 独占摄像头并做拍摄，PodiumCast-Stage 把同一路实时预览放到大屏上，还能远程控制快门、录制、变焦与回放。

下载 Windows 版

Windows x64 · 73.5 MB 其他平台与版本 ↓

两个预览，实时同步

拍摄端看到的画面，和投到大屏上的画面是同一路，几乎没有延迟。

首次连接，自动匹配比例

大屏是什么比例，录制就自动用什么比例，不必自己调参数。

文件存在哪一端，由你决定

默认存在拍摄端，也可以只存大屏端或两端都存，任意一端都能向对端拉取。

下载

说明
安装包未签名
Windows 出现 SmartScreen 提示时点「更多信息」→「仍要运行」；macOS 请右键点击应用图标选择「打开」；Android 需要在系统设置里允许「未知来源」安装。
需要联网吗
不需要。两端通过局域网、USB（adb reverse）或同一台电脑的本机回环直连，不经过任何服务器。
